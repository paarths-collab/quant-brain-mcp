Your credentials stay separate.

The assistant uses an MCP client token. Codex handles its own sign-in profile on the server. The internal service uses another token and remains on loopback.

Tools compute. Models interpret.

Python retrieves provider data and calculates indicators. Codex researches and reviews. Claude then explains and judges the returned evidence.

Bounded by design.

Role and job time limits, authenticated access, finite queues, limited source retrieval, and persistent job status keep the workflow explicit.

What the agents cannot do

Browser/computer control, shell execution, inherited connectors, and nested agent spawning are disabled. Internal roles cannot start recursive research jobs, modify alerts, or place trades. Roles still use live web search; search is not a live exchange-price feed.
